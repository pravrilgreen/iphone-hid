# Third-party software in the box binary

`ihcd` is built from this repository with the following components. Their licences allow
redistribution in binary form with this notice.

| Component | Use | Licence |
|---|---|---|
| [libjpeg-turbo](https://libjpeg-turbo.org/) 3.1 | JPEG encoding of the screen | IJG licence, modified BSD licence, zlib licence |
| [Go standard library](https://go.dev/) | everything | BSD 3-Clause |
| [gorilla/websocket](https://github.com/gorilla/websocket) | WebSockets | BSD 2-Clause |
| [hashicorp/mdns](https://github.com/hashicorp/mdns) | network announcement | MIT |
| [miekg/dns](https://github.com/miekg/dns) | DNS messages for mDNS | BSD 3-Clause |
| [golang.org/x/sys, x/net, x/image](https://pkg.go.dev/golang.org/x) | system calls, networking, fonts of the simulated phone | BSD 3-Clause |
| [Go fonts](https://go.dev/blog/go-fonts) | text of the simulated phone | BSD 3-Clause |
| [Barlow](https://github.com/jpt/barlow) | the web console's typeface | SIL Open Font License 1.1 (web/fonts/OFL.txt) |
