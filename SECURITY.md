# Security

Report a vulnerability privately through GitHub: **Security > Report a vulnerability** on
[the repository](https://github.com/pravrilgreen/iphone-hid/security/advisories/new). Please do not
open a public issue for it. Include the version (`ihcd version`), what an attacker can do, and how
to reproduce it.

Fixes go into the next release; the [changelog](CHANGELOG.md) names them.

What the box protects, and how, is described in the README's
[Security](README.md#security) section and the install guide's
[Network and security](docs/guide/install.md#network-and-security).
